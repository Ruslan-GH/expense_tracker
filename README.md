Консольний додаток для зберігання витрат користувача.

# Функціонал
CRUD для категорій та витрат.
Отримання звітів:
- Фільтрація витрат за датою, назвою, категорією.
- Максимальна витрата у кожній категорії.
- Максимальна витрата у періоді.
- Мінімальна витрата у кожній категорії.
- Мінімальна витрата у періоді.
- Підсумки по категоріях: сума по кожній, топ категорія, середні витрати на день за період

Можливе зберігання звіту по всім витратам в csv або json.

## 🚀 Як запустити проект

1. Клонуйте репозиторій:
   ```bash
   git clone [https://github.com/Ruslan-GH/expense_tracker.git](https://github.com/Ruslan-GH/expense_tracker.git)
   cd expense_tracker

2. Створіть та активуйте віртуальне середовище:
   python -m venv venv
   source venv/bin/activate  # для Mac/Linux
   venv\Scripts\activate     # для Windows

3. Встановіть залежності:
   pip install -r requirements.txt

4. Налаштуйте змінні оточення:
   створіть файл .env у корені та додайте - DATABASE_URL=sqlite:///expenses.db

5. Запустіть додаток:
   python main.py

Проєкт підтримує будь-які БД, сумісні з SQLAlchemy. 
Налаштування доступу здійснюється через файл .env.

## Технології:
- Python 3.x
- SQLAlchemy (ORM)
- SQLite
