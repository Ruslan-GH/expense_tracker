Консольний додаток для для зберігання витрат користувача.

# Функціонал
CRUD для категорій та витрат.
Отрмиання звітів:
- Фільтрація витрат за датою, назвою, категорією.
- Максимальна витрата у кожній категорії.
- Максимальна витрата у періоді.
- Мінімальна витрата у кожній категорії.
- Мінімальна витрата у періоді.
- Підсумки по категоріях: сума по кожній, топ категорія, середні витрати на день за період

Можливе зберігання звіту по всім витратам в файл.

## Технології:
- Python 3.x
- SQLAlchemy (ORM)
- PostgreSQL

## Додатково:
Додано дані, які ініціалізуються при запуску для перевірки функціональності додатку.
